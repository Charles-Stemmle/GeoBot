How it works

Three views of the same place.

Each model contributes a different kind of visual evidence. The consensus combines their scores using configurable weights.

01

Holistic model

Analyzes the full image to learn broad patterns such as architecture, road layout, and the overall scene.

02

Road specialist

Uses a segmented view focused on road-related features, including sidewalks, vehicles, poles, and signs.

03

Environment specialist

Uses a segmented view emphasizing vegetation and terrain that may help distinguish regions.

About the project

Experiment, compare, improve.

GeoBot is an ongoing machine learning project investigating whether specialized visual features can improve country-level image classification.

The percentages shown are model scores, not guaranteed real-world probabilities. Accuracy depends on the image, the training data, and whether the photo resembles examples the models learned from. This is an experimental project, so results should be interpreted with that limitation in mind.
